# Image placeholders to replace

All photographs on the site currently use Unsplash URLs defined in `lib/site.ts`. Swap each `src` for your own file (for example under `public/work/…`) and update the matching `alt` text.

| ID | Where it appears | Suggested replacement |
| --- | --- | --- |
| `hero` | Full-bleed homepage hero | Signature landscape or environmental portrait |
| `work-1` | Work grid — Window light | Soft natural-light portrait |
| `work-2` | Work grid — City hush | Street or travel frame |
| `work-3` | Work grid — Still room | Interior / lifestyle detail |
| `work-4` | Work grid — Field path | Landscape |
| `work-5` | Work grid — Hands at rest | Still-life or gear detail (or any personal favorite) |
| `work-6` | Work grid — Evening walk | Couple / candid portrait |

Also update titles and categories in `lib/site.ts` so captions match your real series.
