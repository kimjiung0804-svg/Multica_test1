# Jiung Kim — photographer portfolio

Next.js site scaffolded from the shadcn preset, then shaped into a single-page photography portfolio.

## Sections

- **Hero** — full-bleed photograph, name, and short introduction
- **About** — who you are and what you shoot
- **Work** — selected photographs
- **Pricing** — session starting points
- **Contact** — prominent email link (`jukim@enabledesign.io`)

Fonts: **Cormorant Garamond** (display) and **Figtree** (body).

Placeholder images and a replacement checklist live in `PLACEHOLDERS.md` and `lib/site.ts`.

## Develop

```bash
pnpm install
pnpm dev
```

```bash
pnpm build
```
